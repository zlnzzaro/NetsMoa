# Netvigator
by 글솝net

## 아이디어 1
1. 학부 공지 선택적 알림
2. 졸업요건 충족 확인

졸업 트랙을 선택하고 그에 맞는 학부 공지 선택적 알림까지 구현

파편화된 정보를 필요한 것만 필터링해서 볼 수 있는 기능 (관심분야, llm으로 골라내면 보여준다)

졸업요건 체커 (앞으로 열리는, 내 전공과 졸업 트랙에 필요한 과목까지 확인해주는 쫘라락 서비스)

프론트) 전공,이수과목 입력 화면, 졸업요건 결과 대시보드, 맞춤 공지 목록 화면 구현

백엔드) 졸업요건 데이터 모으고, 이수과목 입력하면 부족학점 계산하는 로직 구현하고, 학부 공지 크롤링하고 키워드 매칭해서 알림전송 기능 구현

## 아이디어 2
팀 프로젝트(교외 공모전/종프/등): 팀원 모으기 플랫폼. 역할분담/본인스펙/모집글 올릴 수 있는 플랫폼 (약간 게임 파티 모집하듯이)

컴학 학생들과 편하게 소통/사람 모집할 방법이 없다 (공지방/인스타그램 큰 그룹 채팅방이 없다)

세부 필터링(AI/개발/발표) 기능, 알림 받을 수 있게, 관심분야에 따라 홈피드 기능

모집 후 같이 사용할 수 있는 채팅방/소통방 링크까지 보여질 수 있게 비공개 게시글 기능
