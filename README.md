# Netvigator
by 글솝net

1. 학부 공지 선택적 알림
2. 졸업요건 충족 확인
졸업 트랙을 선택하고 그에 맞는 학부 공지 선택적 알림까지 구현

파편화된 정보를 필요한 것만 필터링해서 볼 수 있는 기능 (관심분야, llm으로 골라내면 보여준다)
졸업요건 체커 (앞으로 열리는, 내 전공과 졸업 트랙에 필요한 과목까지 확인해주는 쫘라락 서비스)

프론트는 전공,이수과목 입력 화면 , 졸업요건 결과 대시보드, 맞춤 공지 목록 화면 이런거 구현하면 될거같고

백엔드 졸업요건 데이터 모으고, 이수과목 입력하면 부족학점 계산하는 로직 구현하고, 학부 공지 크롤링하고 키워드 매칭해서 알림전송 하자의 초안

📝 심사 기준

• 기술 완성도 (30점): 서비스의 정상 작동 여부, 구현 수준

• 창의성 (25점): 아이디어의 참신성과 차별성

• 실용성 (25점): 문제 정의의 타당성, 실제 활용 가능성

• 발표 및 협업 (20점): 발표 전달력, 시연 완성도, 팀 내 역할 분담

※ 예선과 본선에 같은 기준을 적용하며, 예선은 제출 자료로 평가합니다
