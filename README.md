# NETogether 넷투게더
by 글솝net

## 현재까지 만든 것

- Spring Boot 서버와 로컬 PostgreSQL 연결 완료.
- `GET /api/v1/health`로 서버 응답 확인.
- `GET /api/v1/posts`로 DB에 직접 넣은 테스트 모집글 조회 확인함. 현재 응답에는 제목, 분류, 모집 상태가 들어감.

## 개발 역할 분담 (당연 조율 가능!)

### 백엔드 1 — 모집글

- 모집글 등록 API 구현. 제목, 설명, 분류와 함께 `백엔드 1명`, `발표 1명`처럼 역할별 모집 인원을 저장.
- 기존 목록 조회에 글 ID와 모집 역할을 추가하고, 글 하나를 열었을 때 상세 내용을 가져오는 API 구현.
- 지원 기능에서 사용할 모집글 ID와 모집 역할 ID를 백엔드 2와 맞춤.
- 글 등록·조회 연결 후 분류·역할 필터, 관심 분야 피드, 모집 마감 구현.

### 백엔드 2 — 로그인·지원·승인

- 로그인과 프로필 구현. 글을 올리거나 지원할 때 서버에서 로그인한 사용자 확인.
- 역할별 지원, 내 지원 현황 조회, 글 작성자의 지원자 목록 조회 및 승인·거절 구현. 역할별 정원을 넘겨 승인되지 않도록 처리.
- 팀 채팅방 링크 저장 및 조회 구현. 글 작성자가 링크를 등록하고, 작성자와 승인된 팀원만 볼 수 있게 함.
- 핵심 흐름이 연결되면 지원 결과 알림 추가.

### 프론트엔드 2명 — 웹 화면 및 API 연결

- 로그인·프로필, 모집글 목록·상세·등록, 지원서 작성, 내 지원 현황, 작성자용 지원자 관리 화면 구현.
- 모집글 상세에서 원하는 역할을 골라 지원할 수 있게 연결하고, 승인된 사용자에게 팀 채팅방 링크를 표시.
- 버튼을 눌러 실제로 글 등록 → 역할 지원 → 작성자 승인 → 팀 채팅방 링크 확인까지 이어지는지 백엔드와 같이 테스트.

## 사용 기술

| 기술 | 사용 용도 |
| --- | --- |
| **Java 21 · Spring Boot** | Java로 백엔드 코드 작성. Spring Boot로 브라우저 요청을 받고 결과를 반환하는 웹 서버 구성. |
| **PostgreSQL 17** | 모집글, 모집 역할, 지원서 등을 저장할 DB로 사용. |
| **Docker Compose** | `compose.yaml`에 PostgreSQL 버전과 실행 설정을 적어 둠. 팀원 각자가 같은 설정으로 개발용 DB를 켤 수 있음. |
| **Flyway** | Spring Boot가 시작할 때 아직 적용되지 않은 SQL 파일을 실행해 DB 테이블을 생성하거나 변경함. 현재 첫 SQL 파일로 사용자·모집글·지원서 등의 테이블 생성. |
| **JdbcClient** | Java 코드에서 PostgreSQL에 SQL을 실행할 때 사용. 현재 모집글 목록 조회에 사용 중. |
| **Gradle** | Spring Boot, PostgreSQL 드라이버 등 필요한 라이브러리를 관리하고 백엔드를 빌드·실행할 때 사용함. |


## 팀원 모으기 플랫폼

1. 종프나 교외 공모전에 나가고 싶은데 같이 할 사람을 어디서 찾아야 할지 모르겠음.
2. 모집글을 봐도 어떤 역할이 비어 있고 내가 들어갈 만한 팀인지 한눈에 파악하기 어려움.

컴학 학생들이 공지방이나 인스타그램에서 편하게 대화하고 팀원을 구할 만한 공간이 부족함. 아는 사람한테 먼저 물어보게 되는데, 아는 사람이 적으면 팀 구하는 것부터 막막. (“나만 아싸일 리 없어!”)

**NETogether**는 공모전, 종프, 스터디 같이 할 사람을 컴학 안에서 모으는 플랫폼. 약간 게임 파티 모집하듯이, `AI 1명 / 백엔드 1명 / 발표 1명`처럼 필요한 역할을 적어서 모집글을 올리고, 지원자는 본인이 해본 프로젝트나 쓸 줄 아는 기술을 프로필에 올릴 수 있음.

AI·개발·발표 같은 역할이나 공모전·스터디 같은 활동 유형으로 모집글을 골라 볼 수 있음. 관심 분야에 맞는 글은 홈 피드에서 모아 보고, 새 모집글이 올라오면 알림으로 받을 수 있게 함.

팀이 꾸려지면 비공개 팀 공간에서 공지나 카톡·디스코드 링크를 공유할 수 있게 함. 글 작성자와 승인된 팀원만 볼 수 있음.

에타·링크드인과의 차별점) **컴학 프로젝트에 필요한 자리를 역할별로 구하고, 지원과 팀 합류까지 같은 글에서 이어갈 수 있다는 점**.
